Integration Setup Guide

Connect your Outlook & Teams to the Task Tracker in ~10 minutes.
No API keys. No admin access. Just your student M365 account.

How it works

1 Email or Teams message arrives in your inbox
2 Make.com (free, like a smarter IFTTT) detects it and sends the details to ntfy.sh
3 ntfy.sh (free relay service) delivers it to your Task Tracker in real time
4 Task appears in your tracker automatically, categorised by urgency
A

Pick your ntfy.sh topic

ntfy.sh is a free push-notification relay. No signup needed — just pick a unique topic name and keep it private.

sunway-yourname-abc123

Use lowercase letters, numbers, and hyphens only. The more unique, the better — anyone who knows the topic name can send to it.

Enter this topic name in the Task Tracker settings (⚙ icon in the top-right).

B

Create a free Make.com account

  1. 1. Go to make.com and click Sign up for free
  2. 2. Sign up with your personal email (Gmail, etc.) — not your college email, to avoid IT restrictions
  3. 3. Free plan gives you 1,000 operations/month — enough for ~30 emails per day
C

Create Scenario 1 — Outlook Emails

Step 1 — New scenario

In Make.com dashboard → click Create a new scenario

Step 2 — Add trigger module

Click the big + circle → search for Microsoft 365 Email → choose Watch Emails

Connect your college Outlook account when prompted (standard OAuth — only you authorise it)

Set Folder to Inbox, Maximum number of results to 1

Step 3 — Add urgency router (optional but recommended)

Add a Router module → create 4 routes with these filters on the email Subject field:

Route 1: subject contains "urgent" OR "deadline" OR "ASAP" → tag = urgent

Route 2: subject contains "cancelled" OR "cancel" → tag = cancelled

Route 3: subject contains "rescheduled" OR "moved to" → tag = rescheduled

Route 4 (else): (no filter — catch-all) → tag = non-urgent

Step 4 — Add HTTP module

After each route (or skip the router and use one HTTP module), add an HTTP → Make a request module:

URL: https://ntfy.sh/YOUR-TOPIC-HERE

Method: POST

Body type: Raw

Content type: application/json

Body (copy-paste this, replace the tag value per route):

{
  "title": "{{1.subject}}",
  "message": "From: {{1.from.emailAddress.address}} | Source: outlook",
  "tags": ["non-urgent"],
  "priority": 3
}

Replace non-urgent with the correct tag for each route: urgent, cancelled, or rescheduled.

Step 5 — Turn on the scenario

Toggle the scenario ON (bottom-left switch). Set scheduling to Immediately or every 1 minute.

D

Create Scenario 2 — Teams Messages

Same process, different trigger

Create a new scenario → add Microsoft Teams → Watch Channel Messages as the trigger

Select your college's team and the channel (e.g. General or your class channel)

HTTP module body for Teams

{
  "title": "{{1.body.content}}",
  "message": "From: {{1.from.user.displayName}} | Source: teams",
  "tags": ["non-urgent"],
  "priority": 3
}

Apply the same router + urgency tags as the Outlook scenario.

✓

Test it

  1. 1. Open your Task Tracker and go to ⚙ Settings → click Send Test Task
  2. 2. A test "Urgent" task should appear in your tracker within 1–2 seconds
  3. 3. Send yourself an email with "urgent" in the subject line and watch it appear automatically

💡 Tips for students

  • • Keep your ntfy.sh topic name private — it's your "channel". Anyone who knows it can post to it.
  • • Make.com free tier resets every month. 1,000 operations = about 30 emails/day — more than enough.
  • • Install the Task Tracker on your iPhone: open it in Safari → Share button → Add to Home Screen
  • • The tracker works offline too — your tasks are always saved in your browser.
  • • You can also manually add tasks anytime with the Add Task button — no automation needed.
